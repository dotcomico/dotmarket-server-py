# 🛒 Supermarket Database Seed

Quick setup for populating your Flask supermarket database with test data.

## 📋 Prerequisites

- Python 3.8+
- Flask backend with models in place
- SQLite or configured database

## 🚀 Quick Start

```bash
# 1. Navigate to your backend folder
cd backend

# 2. Delete your existing database (if any)
rm supermarket.db   # or your database file

# 3. Copy seed_database.py to your backend root
# (same level as src/ folder)

# 4. Run the seed script
python seed_database.py

# 5. Start your server
python -m src.main
```

## 🔄 Re-seeding

To reset your database with fresh data:

```bash
rm supermarket.db
python seed_database.py
```

## 💡 Notes

- The script uses `werkzeug.security.generate_password_hash` for passwords
- All timestamps are auto-generated by SQLAlchemy
- Images from your old database are preserved (paths in `/uploads/`)
- New products have `null` images - your frontend should handle placeholders
